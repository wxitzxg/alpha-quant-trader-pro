## 🗂️ Archive Directory

The [`archive/`](./archive/) directory contains historical documentation organized by category:

```
archive/
├── refactoring/              # Refactoring reports and plans
├── implementation-reports/   # Implementation completion reports
├── documentation/            # Documentation process records
├── design-specs/             # Design specifications
└── implementation-plans/     # Implementation plans
```

**Purpose**: Preserve project history, design decisions, and implementation records for reference and learning.

**Note**: These documents are for historical reference only. For current information, refer to the main documentation sections above.

## 🤖 Superpowers Reports

The [`superpowers/reports/`](./superpowers/reports/) directory contains execution reports and completion summaries generated by the Superpowers plugin during development:

```
superpowers/reports/
├── README.md
├── DOCUMENTATION_REFACTORING_COMPLETE.md
├── PROCESS_DOCS_REORG_COMPLETE.md
├── DEVELOPER_GUIDE_STAGE_2_COMPLETE.md
├── EMOJI_DIRECTORY_NAMES_FIXED.md
└── PROCESS_DOCS_ANALYSIS.md
```

**Purpose**: Document major task completions, problem-solving processes, and execution summaries.

**Note**: These are process reports, not user-facing documentation. They provide insight into the development journey.
