## 💡 Tips for Beginners

1. **Start Small**: Use small amounts for your first few trades
2. **Paper Trade First**: Use the backtest system before real trading
3. **One Strategy at a Time**: Master one strategy before moving to another
4. **Keep Records**: Track your trades and learn from mistakes
5. **Risk Management**: Never risk more than 2% per trade
