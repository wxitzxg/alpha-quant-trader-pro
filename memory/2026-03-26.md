**`alpha-quant-db` 数据库容器永远不能删除！**

原因：
- 数据库包含持久化数据，删除会丢失所有历史数据

- ✅ 可以删除: `alpha-quant-api`, `alpha-quant-redis`
- ❌ 禁止删除: `alpha-quant-db`

## Investoday 财务报表解析修复

### 问题
1. API 返回 `data` 是 list 而非 dict
2. 字段名与 API 返回不匹配 (如 `reportYear` → `reportPeriodEnd`)
3. 利润表、现金流量表解析失败

### 解决
| 方法 | 修复内容 |
|------|----------|
| `get_balance_sheet` | 添加 `isinstance(data, list)` 检查 |
| `get_income_statement` | 同上 |
| `get_cash_flow_statement` | 同上 |
| `_parse_balance_sheet` | `reportPeriodEnd` 解析日期，`totalEquity` 替代 `shareholdersEquity` |
| `_parse_income_statement` | `reportPeriodEnd` 解析日期，`epsBasic` 替代 `eps` |
| `_parse_cash_flow_statement` | `reportPeriodEnd` 解析日期，`cfo/cfi/cff` 字段 |

### Investoday API 字段映射
**资产负债表**:
- `reportPeriodEnd` → 报告期
- `totalAssets` → 总资产
- `totalLiabilities` → 总负债
- `totalEquity` → 股东权益

**利润表**:
- `revenue` → 营业收入
- `netProfit` → 净利润
- `epsBasic` → 基本每股收益

**现金流量表**:
- `cfo` → 经营活动现金流
- `cfi` → 投资活动现金流
- `cff` → 筹资活动现金流

### 波动率接口修复

**问题 1**: `'KLine' object has no attribute 'get'`

**解决**: 修改 `api_server/services/data_source_service.py` 的 `get_kline()` 方法：
- 添加 KLine 对象转字典逻辑
- 支持 Pydantic v2 (`model_dump`) 和 v1 (`dict`)

**问题 2**: `current_price` 返回错误值 (4.63 而非 14.28)

**原因**: K线数据按日期降序排列 (最新在前)，但代码按升序处理

**解决**:
```python
# 应用 limit 限制 (取前 N 条，即最新的数据)
if limit and len(result) > limit:
    result = result[:limit]

# 反转为升序 (最旧在前，最新在后)
result = list(reversed(result))
```
