## 财务指标接口修复

### 问题
- `/api/v1/financial/indicators/601611` 返回 404 "No financial indicators for 601611"
- 原因：存在两个路由处理同一个路径
  - `/api_server/routers/financial.py` - 使用 FinancialService
  - `/api_server/routers/data_source.py` - 使用 DataSourceService (旧实现)
- Gunicorn preload_app=True 导致代码更新后仍使用旧代码

### 解决
1. 修改 `data_source.py` 的 `get_financial_indicators` 路由，使用 FinancialService
2. FinancialService.get_financial_indicators 直接调用 AKShare 的 `stock_yjbb_em` 接口
3. 添加智能日期回退逻辑：如果当前季度数据不完整，自动往前推季度

### 数据源选择
- AKShare `stock_yjbb_em` (业绩报表) - 免费、数据完整
- 2025Q3 数据可用，2025Q4 数据不完整（只有 832 条）

## 三个受限接口分析

### 1. 股票基本信息 (stock/info)

**问题**: Sina/Investoday 不支持，AKShare 网络失败

**替代方案**:
```python
# AKShare - stock_info_a_code_name (股票列表)
df = ak.stock_info_a_code_name()
# 返回: {'code': '601611', 'name': '中国核建'}

# AKShare - stock_individual_info_em (个股信息)
df = ak.stock_individual_info_em(symbol="601611")
# 返回: 最新价、股票代码、股票简称、总股本、流通股、总市值、行业、上市时间
```

### 2. 新闻搜索 (news/search)

**问题**: 新闻服务未实现

**替代方案**:
```python
# AKShare - stock_news_em (东方财富新闻)
df = ak.stock_news_em(symbol="601611")
# 返回: 新闻标题、新闻内容、发布时间、文章来源、新闻链接
```

### 3. 涨幅榜/市场情绪

**问题**: 数据源返回空

**替代方案**:
```python
# AKShare - stock_zh_a_spot_em (A股实时行情)
df = ak.stock_zh_a_spot_em()
# 按涨跌幅排序即可获得涨幅榜
df = df.sort_values('涨跌幅', ascending=False)
```

## 关键发现

### Docker 构建缓存问题
- `docker compose build` 可能使用缓存，导致代码未更新
- 解决方案: `docker compose build --no-cache` 或删除镜像后重建

### 多路由冲突
- FastAPI 按注册顺序匹配路由
- 同一路径可能被多个路由处理器捕获
- 需要检查所有路由文件避免重复定义

### AKShare 数据延迟
- 业绩报表数据有 1-2 季度延迟
- 2025Q4 数据只有 832 条（不完整）
- 2024Q3 数据有 5964 条（完整）
